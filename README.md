# Home Assistant projects

Community configurations and notes for Home Assistant and ESPHome, developed and maintained by Graham van der Wielen.

| Project | Description | Status |
| --- | --- | --- |
| [Eurom Mon Soleil DSP for ESPHome](esphome/eurom-mon-soleil-dsp/README.md) | Local Home Assistant control of a Eurom Mon Soleil DSP WiFi infrared heater through its Tuya MCU | Experimental; 400 W testing in progress |

Each project documents its own requirements, observations and limitations. Device compatibility is only claimed when supported by hardware evidence.

See [CONTRIBUTING.md](CONTRIBUTING.md) for contributions and [AGENTS.md](AGENTS.md) for AI-assisted work.
